# v0.1.8

**English** · [简体中文](#简体中文)

Long reasoning streams stop burning CPU on their own draft and on the live tail, the theme catalogue
grows to 25 palettes whose syntax colours come from the theme itself, an interrupted stream recovers on
the budget its failure deserves, and the streaming idle bound becomes a per-model setting. The release
binaries move to Go 1.27.2, which changes how macOS and Windows resolve certificate roots.

## Install

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows (PowerShell 5.1 or newer):

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

Both check the archive against the release's `SHA256SUMS` before installing. `PIPS_VERSION` pins a tag,
`PIPS_BIN_DIR` selects the directory, and `PIPS_NO_MODIFY_PATH=1` leaves shell and PATH settings alone.

## Added

- The theme catalogue grows to 25 built-in palettes, and a theme's syntax colours are derived from its
  own palette, so a code fence agrees with the theme around it. Everforest (dark and light) and Kanagawa
  ship from their official palettes.
- `auto` follows the desktop's light/dark preference, and opening the theme picker re-asks the terminal
  for its background instead of trusting what it reported at startup.
- The status line names the model's effective reasoning level, read from the resolved model rather than
  the raw configuration. A model that declares levels with none selected shows `(default)`; a model with
  no reasoning knob shows no suffix.
- A reserved band under the transcript keeps the composer from moving as its contents change, carries a
  centred `▼` while newer rows are off screen, and confirms a drag copy. A centred `▲` on the first
  transcript row appears while anything is above the window; clicking it walks back one turn at a time.
- `stream_idle_timeout_seconds`, under `[providers.<p>]` and `[providers.<p>.models.<m>]`. It bounds the
  silence between reads on a streaming response: a stream that stops delivering for that long aborts with
  `ai.ErrStreamIdle` and is replayed. A model's value overrides its provider's, and an absent key keeps
  the ten-minute default. The guard cannot be switched off — an explicit `0` is refused, because a parked
  stream is the one interruption nothing else reaches. Accepts 1 to 3600 seconds.
- `config show` reports `resolved.stream_idle_timeout` and `resolved.retry_window`, so the bound in effect
  and the episode it implies are visible without reading the source.

## Changed

- The header names the release alone: the `git describe` suffix and the dirty marker are dropped, and a
  build with no version reads `dev`.
- The retry window follows the idle bound: `max(10m, 2×idle)`, for both the per-request replay episode
  and one turn's re-issue episode. With no bound configured it stays at twenty minutes.
- The release binaries are built with Go 1.27.2, and building from source requires it. Go 1.27 changes
  the default of `x509sslcertoverrideplatform` to `1`: on macOS and Windows, a set `SSL_CERT_FILE` or
  `SSL_CERT_DIR` now selects the certificate roots loaded from disk, where those variables were
  previously ignored in favour of the system store. A machine whose `SSL_CERT_FILE` names an incomplete
  bundle can newly fail TLS verification, which pips reports as a non-retryable error rather than
  retrying. `GODEBUG=x509sslcertoverrideplatform=0` restores the previous behaviour.
- Tracebacks and `debug=2` stack dumps include goroutine labels, which Go 1.27 enables by default.

## Fixed

- The composer and the search field no longer paint their own background, so a light theme no longer
  draws a white band across the input inside a dark terminal.
- Fenced code no longer takes its colours from a chroma style that whichever theme rendered a fence first
  had registered for the process.
- Markdown surfaces — the `H1` band and the inline-code fill — are painted only when the theme's
  background family is the one the terminal reported. A mismatch and an unanswered probe both leave the
  cell to the terminal.
- A compact tool preview is no longer written back while rendering, so switching themes mid-session
  stopped growing `└` prefixes and stale colour escapes inside the text.
- Releasing a drag selection writes the clipboard only, instead of also writing the saver's fallback
  file. `/copy`, `/export`, and a copy with a path keep theirs.
- A cancelled turn's controller cancel is delivered before the turn ends, so a session waiting on it no
  longer waits out its full timeout.
- A command's captured output is drained before it is reported, so the retained capture and its byte
  count describe what the process wrote rather than how quickly its readers were scheduled.
- A failed output sink is reported as itself instead of being replaced by the operation deadline.
- The standard-library and module advisories the vulnerability gate reported are cleared; the shipped
  binaries no longer build on the Go 1.26 line.
- A stream that broke after streaming only reasoning was retried on the three-attempt re-issue budget and
  made the model think the whole thing through again. Reasoning is now treated as output a consumer can
  drop, so that failure draws the same ten replays as a request that produced nothing, while answer text
  and tool calls keep the shorter budget.
- A turn that gives up after streaming only reasoning no longer leaves the partial thinking on screen
  beside the error.

## Performance

- The un-frozen live tail is no longer re-rendered every frame once it passes 8 KiB. On a 98 KiB open
  fence at the TUI's own 33 ms cadence over 60 frames: 7.6 repaints a second, worst lag 240 ms. For the
  whole process on the reproducing workload: CPU 5.77 s → 3.53 s, mean CPU 48.3% → 29.5%, allocations
  6.24 GB → 2.77 GB, GC cycles 464 → 202. Below the threshold a frame is still rendered every time, so a
  small body stays byte-identical to a whole render.
- Streaming a long reasoning response no longer copies the draft on every delta. On the fixed replay
  (20k reasoning deltas, ~10 s): CPU 17.2 s → 3.5 s in the repeat shape and 19.9 s → 2.9 s in the prose
  shape, allocations 45.6 GB → 0.3 GB, GC cycles 2,744 → 60, peak RSS 214 MB → 85 MB on the heaviest
  shape.

## Verification

- The full matrix on the released commit: Quality (build, `go vet`, `golangci-lint`, `go mod verify`,
  `govulncheck`, the dependency policy check, and the platform-semantics tests), Agent Plugins on macOS,
  Ubuntu and Windows, and the four sandbox jobs. Race tests run over `agent` and `internal/coding`.
- `go mod tidy -diff` is empty, so the module graph is unchanged.
- The idle bound reaches the transport end to end: a configured one-second bound aborts a stalled test
  stream with `ai.ErrStreamIdle`, and the bytes delivered before the silence survive.
- The numbers above come from the fixed replay harness, which compares every visible text and reasoning
  byte against an independent source prefix frame by frame, and from the TUI's own frame cadence on a
  98 KiB open fence.
- No live provider was called for this release; the real-provider smoke suite is opt-in and did not run.

## 简体中文

**简体中文** · [English](#v018)

长思考的流不再为自己的草稿和活动尾部烧 CPU；主题目录扩到 25 套配色，语法高亮取自主题自身的调色板；
中断的流按失败本身的量级重放；流空闲上界变成按模型可配置。发布产物改用 Go 1.27.2 构建，这改变了
macOS 与 Windows 上根证书的解析方式。

## 安装

macOS 与 Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows（PowerShell 5.1 及以上）：

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

两者都会先用发布出来的 `SHA256SUMS` 校验归档再安装。`PIPS_VERSION` 固定版本，`PIPS_BIN_DIR` 指定安装
目录，`PIPS_NO_MODIFY_PATH=1` 不改动 shell 与 PATH 设置。

## 新增

- 主题目录扩到 25 套内置配色，且每个主题的语法高亮由它自己的调色板推导，代码块与周围的主题一致。
  Everforest（深色与浅色）与 Kanagawa 采用其官方调色板。
- `auto` 会跟随桌面的浅色/深色偏好；打开主题选择器时会重新询问终端背景，而不是沿用启动时的结果。
- 状态栏显示模型实际生效的 reasoning 级别，取自解析后的模型而非原始配置。声明了级别但未选中的模型显示
  `(default)`；没有 reasoning 开关的模型不显示后缀。
- 转录下方预留一条固定带，内容变化时输入框不再移动；它在还有更新的行在屏幕外时显示居中的 `▼`，并确认
  拖拽复制。转录首行在窗口上方仍有内容时显示居中的 `▲`，点击它可逐轮往回翻阅。
- `stream_idle_timeout_seconds`，可写在 `[providers.<p>]` 与 `[providers.<p>.models.<m>]`。它约束流式
  响应两次读取之间的静默：静默超过该值即以 `ai.ErrStreamIdle` 中止并重放。模型的值覆盖其 provider 的
  值，缺省保持十分钟。该保护无法关闭——显式写 `0` 会被拒绝，因为停住的流是其他机制够不到的那类中断。
  取值 1 到 3600 秒。
- `config show` 会输出 `resolved.stream_idle_timeout` 与 `resolved.retry_window`，不用读源码就能看到
  生效的上界及由此推出的重放区间。

## 变更

- 顶部标题只显示版本号：去掉 `git describe` 后缀与 dirty 标记；没有版本信息的构建显示 `dev`。
- 重试窗口跟随空闲上界：`max(10m, 2×idle)`，同时作用于单次请求的重放区间与单轮会话的重发区间。未配置
  该上界时仍是二十分钟。
- 发布产物改用 Go 1.27.2 构建，从源码构建也需要它。Go 1.27 把 `x509sslcertoverrideplatform` 的默认值
  改为 `1`：在 macOS 与 Windows 上，设置了 `SSL_CERT_FILE` 或 `SSL_CERT_DIR` 时，会由它们决定从磁盘加载
  哪些根证书；此前这两个变量在这两个平台被忽略，只用系统证书库。若机器的 `SSL_CERT_FILE` 指向不完整的
  证书包，现在会新出现 TLS 校验失败，而 pips 会把它作为不可重试的错误上报而不是重试。
  `GODEBUG=x509sslcertoverrideplatform=0` 可退回原有行为。
- 栈回溯与 `debug=2` 的栈转储会带上 goroutine 标签，这是 Go 1.27 的默认行为。

## 修复

- 输入框与搜索框不再自带背景，浅色主题不会在深色终端里给输入行画一条白带。
- 代码块不再使用进程内"第一个渲染围栏的主题"注册进 chroma 的样式。
- Markdown 的表面——`H1` 色带与行内代码底色——只在主题的背景族与终端报告的一致时才绘制；不一致与探测
  无应答都把该单元格交回终端。
- 紧凑工具预览在渲染时不再被回写，因此会话中切换主题不再累积 `└` 前缀与残留在文本里的颜色转义。
- 拖拽选中松手只写剪贴板，不再同时写 saver 的兜底文件；`/copy`、`/export` 与带路径的复制保留原有行为。
- 被取消的轮次会在轮次结束前送达控制器的取消，等待它的会话不再白等到超时。
- 命令的捕获输出先排空再上报，保留下来的内容与字节数描述的是进程实际写了什么，而不是读取协程被调度的
  快慢。
- 输出 sink 失败时按它本身上报，不再被操作截止时间顶替。
- 漏洞闸门报出的标准库与模块公告已清除；发布产物不再构建在 Go 1.26 线上。
- 只流出了思考就中断的流，此前会按三次重发的预算重试，并让模型把整段思考重做一遍。现在 reasoning 被
  当作可以丢弃的输出，这类失败拿到与"什么都没产出"相同的十次重放，而答案文本与工具调用仍走更短的预算。
- 只流出思考后最终放弃的轮次，不再把半截思考留在屏幕上和错误并排显示。

## 性能

- 活动尾部超过 8 KiB 后不再每帧重绘。在一段 98 KiB 的未闭合围栏上、按 TUI 自身 33 ms 的帧节奏跑 60 帧：
  每秒重绘 7.6 次，最坏滞后 240 ms。同一负载下的整个进程：CPU 5.77 s → 3.53 s，平均 CPU 48.3% → 29.5%，
  分配 6.24 GB → 2.77 GB，GC 次数 464 → 202。低于阈值时仍然每帧渲染，因此小内容与整体渲染逐字节一致。
- 流式输出长思考时不再为每个增量复制整份草稿。在固定回放上（2 万个 reasoning 增量，约 10 秒）：重复型
  形状 CPU 17.2s → 3.5s、散文型形状 19.9s → 2.9s，分配 45.6 GB → 0.3 GB，GC 次数 2,744 → 60，最重形状
  的峰值 RSS 214 MB → 85 MB。

## 验证

- 发布提交上跑完整矩阵：Quality（构建、`go vet`、`golangci-lint`、`go mod verify`、`govulncheck`、依赖
  策略检查、平台语义测试）、macOS / Ubuntu / Windows 上的 Agent Plugins，以及四个 sandbox 任务；另有
  `agent` 与 `internal/coding` 的竞态测试。
- `go mod tidy -diff` 为空，模块图未变。
- 空闲上界端到端到达传输层：配置一秒上界后，停滞的测试流以 `ai.ErrStreamIdle` 中止，且静默前已送达的
  字节仍然保留。
- 上面的数字来自固定回放装置（它会把每一个可见的文本与 reasoning 字节逐帧与独立的源前缀比对）以及 TUI
  在 98 KiB 未闭合围栏上的自身帧节奏。
- 本次发布没有调用真实 provider；真机冒烟套件是可选开启的，未运行。
