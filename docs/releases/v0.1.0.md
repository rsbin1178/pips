# v0.1.0

**English** · [简体中文](#简体中文)

`pips` is a keyboard-first terminal coding agent whose file mutations are confined by the operating
system's own sandbox. It ships with the Go libraries it is built from, so an application can use the same
provider clients, tool loop, and session store the terminal agent runs on.

## What's in the release

- **Terminal agent** — `pips` runs the model in a full-screen session with plan review, approvals, and
  background work.
- **Go libraries** — `ai` for the provider clients, `agent` for a bounded tool-calling loop over durable
  sessions, `workflow` for deterministic pipelines.
- **Packaged release** — one archive per platform with `SHA256SUMS`, and an installer for macOS, Linux,
  and Windows.

## Install

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows (PowerShell 5.1 or newer):

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

Both resolve the latest release, verify the archive against its `SHA256SUMS` entry, and refuse to
install on a mismatch. `PIPS_VERSION` pins a tag, `PIPS_BIN_DIR` selects the directory, and
`PIPS_NO_MODIFY_PATH=1` leaves shell and PATH settings alone.

## Requirements

- **Go 1.27.3** or later to build from source; the archives are self-contained.
- **Sandbox backend** — Seatbelt on macOS, Bubblewrap on Linux. Native Windows has none, so commands
  there need `--sandbox full-access`, or `pips` must run inside WSL2 where the default sandbox applies.

## Added

### Session and interface

- **Streaming transcript** — reasoning and tool activity arrive as they happen, with syntax highlighting
  and a live status line.
- **Resume and fork** — the picker reopens a session with its transcript, tool cards, and usage.
- **Compaction** — the context window compacts automatically, and the boundary is a `Context compacted`
  divider that survives resume.
- **Commands** — `/model` sets the default model, variant, and reasoning effort; `/help` lists shortcuts;
  `/permissions`, `/skills`, `/resume`, and `/new` open their panels.

### Plan mode and approvals

- **Guarded plan** — the model drafts into an isolated session file; each hunk is inspected, commented on,
  revised, or approved before anything is written.
- **Durable approvals** — operations that leave the workspace wait for a decision, and the pending set
  survives a restart.

### Sandbox

- **Three scopes** — `workspace-write` confines writes to the workspace, `read-only` refuses them,
  `full-access` runs unconfined.
- **Network isolation** — per-scope rules, with the active scope shown in `/permissions`.

### Providers

- **OpenAI** — Chat Completions and Responses.
- **Anthropic** — Messages, with prompt caching and thinking.
- **Gemini** — generateContent, with structured output.
- **Bounded waits** — a request without response headers aborts, and a stream that stops delivering is
  replayed instead of hanging.
- **Client identity** — every request carries `pips/<version>`, overridable per provider or model.

### Subagents and background work

- **`spawn_subagent`** — takes a `subagent_type`, `cwd`, `model`, `resume_from`, and
  `isolation = "worktree"`.
- **Messaging** — `send_subagent_message` steers or wakes a running child.
- **Background tasks** — `monitor`, `get_task_output`, `wait_tasks`, and `kill_background_task` address
  work that outlives the tool call that started it.
- **Tasks pane** — commands and watchers are listed per session, each with a detail page.

### Skills and MCP

- **Skills** — Agent Skills load from the workspace and the user's shared roots, are activated by name
  through the `skill` tool, and are toggled in `/skills`.
- **MCP** — stdio and HTTP servers, configured per user or per trusted workspace, with `pips mcp doctor`
  reporting configuration and connectivity.

### Storage

- **Session store** — one directory per session: `session.json` index, event journal, model snapshots,
  media sidecars, archives, and checkpoints.
- **Maintenance** — `pips session migrate` converts a legacy store; `pips session gc` removes
  unreferenced media.

### Command line

- **`pips`** — the interactive agent.
- **`pips exec`** — one non-interactive interaction from an argument, stdin, or `-`; `--goal` continues
  toward a completion condition under a token budget.
- **`pips config`**, **`pips doctor`**, **`pips update`**, **`pips version`** — layered configuration,
  environment probing, self-update, and the build stamp.

### Go libraries

- **`ai`** — typed requests, streaming events, tool schemas, and the three provider clients.
- **`agent`** — the bounded model/tool loop with typed tools, guardrails, steering, and ordered events;
  `agent/harness` adds durable sessions, compaction, and checkpoints, and `agent/continuation`,
  `agent/goal`, `agent/loop`, `agent/team`, and `agent/catalog` build on both.
- **`workflow`** — versioned DAGs with schema contracts, conditional branches, and checkpoint resume.

## Verification

- The quality gate runs the full test suite, a race pass over `./agent/...` and `./internal/coding/...`,
  `go vet`, `golangci-lint`, `go mod verify`, `govulncheck`, the dependency policy check, workflow lint,
  and a build of every package.
- The portable Agent Harness runs on Ubuntu, macOS, and Windows; the sandbox matrix covers Linux
  amd64/arm64 and macOS.
- The release workflow rebuilds every archive from the tag, checks the stamped `linux/amd64` binary, and
  installs the published release with both installers before the release stands.

## 简体中文

**简体中文** · [English](#v010)

`pips` 是一个键盘优先的终端编码代理，文件改动由操作系统自带的沙箱约束。它与构建它的 Go 库一起发布，
应用可以直接复用终端代理所用的模型客户端、工具循环与会话存储。

## 这个版本有什么

- **终端代理** — `pips` 在全屏会话里运行模型，支持方案评审、审批与后台任务。
- **Go 库** — `ai` 提供模型客户端，`agent` 在持久会话上提供有界的工具调用循环，`workflow` 提供确定性
  的流程编排。
- **发布包** — 每个平台一个归档并附 `SHA256SUMS`，macOS、Linux、Windows 各有安装脚本。

## 安装

macOS 与 Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows（PowerShell 5.1 及以上）：

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

两者都会解析最新发布，用归档对应的 `SHA256SUMS` 条目校验，不匹配就拒绝安装。`PIPS_VERSION` 固定 tag，
`PIPS_BIN_DIR` 指定安装目录，`PIPS_NO_MODIFY_PATH=1` 不改动 shell 与 PATH 设置。

## 环境要求

- **Go 1.27.3** 或更高版本用于从源码构建；发布归档自带运行时。
- **沙箱后端** — macOS 用 Seatbelt，Linux 用 Bubblewrap。原生 Windows 没有后端，那里的命令只能加
  `--sandbox full-access` 运行，或者把 `pips` 放进 WSL2 里沿用默认沙箱。

## 新增

### 会话与界面

- **流式转录** — 推理与工具活动实时到达，带语法高亮与实时状态栏。
- **恢复与分叉** — 选择器重新打开会话时，转录、工具卡片与用量一并恢复。
- **压缩** — 上下文窗口自动压缩，边界是一条 `Context compacted` 分隔行，恢复后依然保留。
- **命令** — `/model` 设置默认模型、变体与推理档位；`/help` 列出快捷键；`/permissions`、`/skills`、
  `/resume`、`/new` 打开各自面板。

### Plan 模式与审批

- **受保护的方案** — 模型把方案写进独立的会话文件；每个改动块都要经过查看、批注、修订或批准才落盘。
- **持久审批** — 越出工作区的操作等待明确决定，待处理集合在重启后仍保留。

### 沙箱

- **三档范围** — `workspace-write` 把写操作限制在工作区，`read-only` 拒绝写，`full-access` 不受约束。
- **网络隔离** — 按范围生效的规则，当前范围在 `/permissions` 中可见。

### 模型接入

- **OpenAI** — Chat Completions 与 Responses。
- **Anthropic** — Messages，支持提示缓存与 thinking。
- **Gemini** — generateContent，支持结构化输出。
- **有界等待** — 等不到响应头的请求会中止，停止投递的流会被重放而不是挂住。
- **客户端标识** — 每个请求带 `pips/<version>`，可按 provider 或模型覆盖。

### 子代理与后台任务

- **`spawn_subagent`** — 接受 `subagent_type`、`cwd`、`model`、`resume_from` 与
  `isolation = "worktree"`。
- **消息** — `send_subagent_message` 在子代理运行时引导或唤醒它。
- **后台任务** — `monitor`、`get_task_output`、`wait_tasks`、`kill_background_task` 处理生命周期长于
  发起它的工具调用的工作。
- **任务面板** — 每个会话列出命令与 watch，每行都有详情页。

### Skills 与 MCP

- **Skills** — Agent Skills 从工作区与用户的共享目录加载，由 `skill` 工具按名称激活，在 `/skills` 中开关。
- **MCP** — 支持 stdio 与 HTTP 服务，按用户或受信工作区配置，`pips mcp doctor` 报告配置与连通性。

### 存储

- **会话存储** — 每个会话一个目录：`session.json` 索引、事件日志、模型快照、媒体 sidecar、归档与检查点。
- **维护** — `pips session migrate` 转换旧存储；`pips session gc` 清掉未被引用的媒体。

### 命令行

- **`pips`** — 交互式代理。
- **`pips exec`** — 执行一次非交互调用，输入可来自参数、stdin 或 `-`；`--goal` 在 token 预算内向完成
  条件推进。
- **`pips config`**、**`pips doctor`**、**`pips update`**、**`pips version`** — 分层配置、环境探测、
  自更新与构建戳。

### Go 库

- **`ai`** — 类型化请求、流式事件、工具 schema，以及三个模型客户端。
- **`agent`** — 有界的模型/工具循环，带强类型工具、护栏、引导与有序事件；`agent/harness` 在其上提供
  持久会话、压缩与检查点，`agent/continuation`、`agent/goal`、`agent/loop`、`agent/team`、
  `agent/catalog` 建在两者之上。
- **`workflow`** — 带版本的 DAG，支持模式契约、条件分支与断点续跑。

## 验证

- 质量门运行完整测试、`./agent/...` 与 `./internal/coding/...` 的 `-race`、`go vet`、`golangci-lint`、
  `go mod verify`、`govulncheck`、依赖策略检查、workflow lint 与全量构建。
- 可移植 Agent Harness 在 Ubuntu、macOS、Windows 上运行；沙箱矩阵覆盖 Linux amd64/arm64 与 macOS。
- 发布流程从 tag 重新构建每个归档，校验带构建戳的 `linux/amd64` 二进制，并用两个安装脚本安装发布产物
  之后才对外发布。
