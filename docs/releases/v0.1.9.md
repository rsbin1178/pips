# v0.1.9

**English** · [简体中文](#简体中文)

Delegated subagents can be resumed, isolated in a worktree, and messaged while they run. Background commands
and watches continue after the tool call, sessions move to a layered store with a migration command, images
and files persist through the request pipeline, and compaction marks its boundary in the transcript.
Streaming requests also bound the wait for response headers and identify the client on the wire.

## Install

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows (PowerShell 5.1 or newer):

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

Both check the archive against the release's `SHA256SUMS` before installing. `PIPS_VERSION` pins a tag,
`PIPS_BIN_DIR` selects the directory, and `PIPS_NO_MODIFY_PATH=1` leaves shell and PATH settings alone.

## Added

- `spawn_subagent` accepts `subagent_type`, `isolation`, `cwd`, `resume_from`, and `model`.
  `isolation = "worktree"` runs the child in a preserved Git worktree; `resume_from` continues a completed
  child with its transcript, tool calls, and usage.
- Roles and personas are named presets selected by the resolved subagent type. They load from user and
  trusted-project roots or inline `[subagents.roles.*]` and `[subagents.personas.*]` tables.
- `send_subagent_message` steers, queues, interjects, or wakes a child while it runs. The message surface
  stays off until `active_agent_messages = true`.
- Background work is addressable by ID: `monitor` starts a watch, `get_task_output` reads a command or child,
  `wait_tasks` blocks on it, and `kill_background_task` stops it. A `shell` call with `block_until_ms = 0`
  now outlives its tool call.
- The tasks pane lists one-shot commands under Tasks and watches under Watchers, opens a detail page per row,
  and moves the todo checklist to `/todos`.
- Goal checks run a panel of independent verifier subagents with the goal's transcript, diff, and changed-file
  list. A repeated blocker pauses the goal for a decision.
- Session store v2 keeps one directory per session with a `session.json` index, a durable event journal,
  model snapshots, sidecars, archives, and checkpoints. `pips session migrate` converts a legacy store;
  `pips update` installs a published release.
- Composer attachments accept images and files. `read` returns PNG, JPEG, and GIF files as image parts and
  renders Jupyter notebooks as bounded cell text. Session media is content-addressed, copied on fork, and
  removed by `pips session gc`.
- `[media]` sets `max_request_bytes`, `cleanup_ttl_days`, and `gc_grace_hours`.
- Provider tool results carry image and file parts. A provider that cannot express the shape reports an error
  instead of dropping the bytes.
- Project MCP servers follow workspace trust, with a user-level deny by server ID. `pips mcp doctor` reports
  configuration and connectivity, transient handshakes retry, and a lost transport recovers.
- `pips doctor` probes `HTTPS_PROXY` with a CONNECT request and reports latency or a credential-free failure
  category.
- `todo_write` replaces `update_plan`. `/todos` and Ctrl+P open the checklist; the status line shows remaining
  items only while work remains.
- `/model` writes the selected model, variant, and reasoning to the active config file as its default.
- `/help` and Ctrl+X open a shortcut and command panel.
- A successful compaction paints a `Context compacted` divider with its mode and before/after token counts.
  The boundary survives resume.
- `resume` opens a fullscreen session with its own banner.
- Filesystem tools accept workspace-relative paths and absolute paths confined to the workspace, and clean
  quotes, trailing escapes, and a leading tilde. Patch targets use the same resolver.

## Changed

- `[subagent]` is now `[subagents]`. `limit_behavior` selects `queue` (default) or `fail`;
  `structured_results` defaults to false; a child has no execution budget unless a definition sets
  `limits.max_turns`.
- **Action required:** remove `max_spawned_per_root_interaction`, `max_auto_follow_ups`, `max_turns`,
  `max_tokens`, `max_tool_calls`, and `max_duration_minutes` from `[subagents]`. The strict loader rejects
  them and names the replacement.
- **Action required:** project MCP servers need a trusted workspace. Use `pips mcp list` and `pips mcp doctor`
  after changing trust; a user-level deny keeps a server off by ID.
- **Action required:** run `pips session migrate` before opening an existing store with this release.
- Every request sends `User-Agent: pips/<version>`. `user_agent` replaces it per provider or model, and
  `user_agent_enabled = false` omits it. A gateway that filters on `User-Agent` must allow `pips/`.
- Streaming waits are bounded in the header phase and between reads: a request with no response headers
  aborts with `ai.ErrResponseTimeout` after ten minutes, an idle HTTP/2 connection is pinged after 30 seconds
  and closed after 10 seconds without an answer, and TCP keepalive uses a 30-second idle, 10-second interval,
  and three probes.
- `todo_write` merges by item ID by default. `merge = false` replaces the list and `clear = true` removes it.
  Replayed `update_plan` calls keep replace semantics.
- The journal keeps live projections out of durable records, so message deltas, retry notices, and tree
  snapshots stay in the event stream. Durable records are written at their natural size.

## Fixed

- A successful compaction now leaves a visible boundary in the transcript; a resumed compacted session places
  it at the checkpoint even when the session tree is truncated.
- Replaying a child snapshot no longer fails when the subscription still has events the snapshot already
  applied.
- A committed message larger than the old journal record budget is no longer dropped.
- The terminal caret blinks again after a full repaint.
- The tasks pane's history chord works while the conversation has focus.
- A stopped turn settles the tool calls it left unanswered.

## Performance

- Session listing reads `session.json` and never a transcript. Model snapshots, sidecars, archives, and
  checkpoints stay under the session directory.

## Verification

- The quality workflow ran on this branch: the full test suite, race tests over `agent` and
  `internal/coding`, provider adapter smoke, `go vet`, `golangci-lint`, `go mod verify`, `govulncheck`, the
  dependency policy check, both installers, workflow lint, and a build.
- Agent Plugins ran on macOS, Ubuntu, and Windows. The sandbox matrix ran Linux amd64/arm64 and macOS.
- The release workflow rebuilds every archive, checks the stamped `linux/amd64` binary, and installs the
  published release with both installers.

## 简体中文

**简体中文** · [English](#v019)

子代理可以恢复、在独立 worktree 中运行，并在运行期间接收消息。后台命令与 watch 在工具调用结束后继续
运行；会话改用分层存储，并提供迁移命令；图片与文件会贯穿整个请求链路；压缩会在转录中标记边界。流式
请求同时为等待响应头设了上界，并在请求中标明客户端身份。

## 安装

macOS 与 Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/rsbin1178/pips/main/install.sh | sh
```

Windows（PowerShell 5.1 及以上）：

```powershell
irm https://raw.githubusercontent.com/rsbin1178/pips/main/install.ps1 | iex
```

两者都会先用发布出来的 `SHA256SUMS` 校验归档再安装。`PIPS_VERSION` 固定版本，`PIPS_BIN_DIR` 指定安装
目录，`PIPS_NO_MODIFY_PATH=1` 不改动 shell 与 PATH 设置。

## 新增

- `spawn_subagent` 支持 `subagent_type`、`isolation`、`cwd`、`resume_from` 与 `model`。
  `isolation = "worktree"` 让子代理在保留的 Git worktree 中运行；`resume_from` 带上转录、工具调用与
  用量继续一个已完成的子代理。
- 角色与 persona 是按解析后的子代理类型选择的命名预设，可从用户目录、受信任项目目录或内联的
  `[subagents.roles.*]`、`[subagents.personas.*]` 表加载。
- `send_subagent_message` 可以向运行中的子代理发送 steer、排队、插话或唤醒消息。消息面默认关闭，需设置
  `active_agent_messages = true`。
- 后台工作可以按 ID 操作：`monitor` 启动 watch，`get_task_output` 读取命令或子代理，`wait_tasks` 阻塞
  等待，`kill_background_task` 停止。`shell` 使用 `block_until_ms = 0` 时，命令会在工具调用结束后继续
  运行。
- Tasks 面板把一次性命令列在 Tasks 下，把 watch 列在 Watchers 下，每行都有详情页；todo 清单移到
  `/todos`。
- Goal 校验由一组独立子代理完成，读取 Goal 的转录、diff 与变更文件列表。同一个阻塞项反复出现时会暂停
  Goal，等待用户决定。
- 会话存储 v2 每个会话一个目录，包含 `session.json` 索引、持久事件 journal、模型快照、sidecar、归档与
  checkpoint。`pips session migrate` 迁移旧存储；`pips update` 安装已发布的版本。
- Composer 支持附加图片与文件。`read` 把 PNG、JPEG、GIF 作为图片部件返回，并把 Jupyter notebook 渲染为
  有界单元格文本。会话媒体按内容寻址，fork 时复制，`pips session gc` 负责清理。
- `[media]` 可设置 `max_request_bytes`、`cleanup_ttl_days` 与 `gc_grace_hours`。
- Provider 的工具结果可以携带图片与文件部件。无法表达该结构的 provider 会返回错误，而不是丢掉字节。
- 项目 MCP 服务器跟随 workspace 信任，并可按服务器 ID 在用户层禁用。`pips mcp doctor` 报告配置与连通性；
  瞬时握手失败会重试，丢失的传输会恢复。
- `pips doctor` 用 CONNECT 请求探测 `HTTPS_PROXY`，报告延迟或不含凭据的失败类别。
- `todo_write` 取代 `update_plan`。`/todos` 与 Ctrl+P 打开清单；状态栏只在仍有工作时显示剩余项。
- `/model` 把选中的模型、variant 与 reasoning 写入当前配置文件，作为默认值。
- `/help` 与 Ctrl+X 打开快捷键与命令面板。
- 压缩成功后，转录显示一条 `Context compacted` 分割线，附带触发方式与压缩前后的 token 数。resume 后
  边界仍在。
- `resume` 进入全屏会话时显示该会话自己的 banner。
- 文件系统工具接受 workspace 相对路径和工作区内的绝对路径，并清理引号、结尾转义与前导 `~`。补丁目标
  使用同一套解析。

## 变更

- `[subagent]` 改为 `[subagents]`。`limit_behavior` 可选 `queue`（默认）或 `fail`；`structured_results`
  默认关闭；子代理没有执行预算，除非定义中设置了 `limits.max_turns`。
- **需要操作：** 从 `[subagents]` 删除 `max_spawned_per_root_interaction`、`max_auto_follow_ups`、
  `max_turns`、`max_tokens`、`max_tool_calls` 与 `max_duration_minutes`。严格加载器会拒绝这些键，并
  指出替代项。
- **需要操作：** 项目 MCP 服务器需要受信任的 workspace。修改信任后使用 `pips mcp list` 与
  `pips mcp doctor` 检查；用户层禁用可按 ID 保持关闭。
- **需要操作：** 使用本版本打开旧存储前先运行 `pips session migrate`。
- 每个请求发送 `User-Agent: pips/<version>`。`user_agent` 可按 provider 或模型替换它，
  `user_agent_enabled = false` 则完全不发。按 `User-Agent` 过滤的网关需要放行 `pips/`。
- 流式等待在响应头阶段与两次读取之间都有上界：响应头十分钟未到会以 `ai.ErrResponseTimeout` 中止；空闲
  HTTP/2 连接在 30 秒后 ping，10 秒无应答即关闭；TCP keepalive 使用 30 秒空闲、10 秒间隔与三次探测。
- `todo_write` 默认按 item ID 合并。`merge = false` 替换整个列表，`clear = true` 清空。重放历史
  `update_plan` 调用时仍按替换语义处理。
- Journal 不再把 live projection 写入持久记录，消息增量、重试提示与 tree 快照只留在事件流里。持久记录按
  实际大小写入。

## 修复

- 压缩成功后转录会留下可见边界；resume 已压缩会话时，即使 Session tree 被截断，分割线也会落在
  checkpoint 处。
- 子代理快照已应用过的事件仍留在订阅队列时，重放不再失败。
- 超过旧 journal 记录预算的已提交消息不再被丢弃。
- 完整重绘后终端光标恢复闪烁。
- 会话获得焦点时，Tasks 面板的历史快捷键仍然有效。
- 被停止的轮次会补齐它留下的未应答工具调用。

## 性能

- 会话列表只读 `session.json`，不再读取转录。模型快照、sidecar、归档与 checkpoint 都放在会话目录下。
